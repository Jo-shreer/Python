# Counter in Python

## What is `Counter`?
`Counter` is used to **count how many times each value appears**.
It comes from the `collections` module.

### Python
```python
from collections import Counter
numbers = [1, 2, 2, 3, 3, 3]
counts = Counter(numbers)
print(counts)
```

### Output
```text
Counter({3: 3, 2: 2, 1: 1})
```
Meaning:

```text
1 → appears 1 time
2 → appears 2 times
3 → appears 3 times
```
---

## When to Use `Counter`

Use `Counter` when you need to:
- Count frequencies
- Find the most common values
- Count statuses
- Count categories
- Count words
- Analyze records
- Find duplicates

For ETL, this is useful for **data profiling and validation**.
---

# 1. Count Values
### Python

```python
from collections import Counter

statuses = [
    "success",
    "failed",
    "success",
    "success",
    "failed"
]

```

### Output

```text
Counter({
    'success': 3,
    'failed': 2
```

# 2. Get Count of One Value

### Python
```python

```

### Output
```text

```
Pattern:

```python

```

# 3. Most Common Values
One of the most important `Counter` methods is:

```python
most_common()
```
### Python

```python
from collections import Counter

numbers = [1, 2, 2, 3, 3, 3]
counts = Counter(numbers)
print(counts.most_common())
```

### Output

```text
[(3, 3), (2, 2), (1, 1)]
```

This means:
```text
3 → 3 times
2 → 2 times
1 → 1 time
```
---

# 4. Top N Most Common
You can specify how many values you want.

### Python
```python
from collections import Counter
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
counts = Counter(numbers)
print(counts.most_common(2))
```

### Output
```text
[(4, 4), (3, 3)]
```

Meaning:
```text
Top 2 values:
4 → 4 times
3 → 3 times
```

# 7. ETL Example — Count Status
Suppose you receive records from an API.

### Python
```python
from collections import Counter
records = [
    {"id": 1, "status": "success"},
    {"id": 2, "status": "failed"},
    {"id": 3, "status": "success"},
    {"id": 4, "status": "success"},
    {"id": 5, "status": "failed"}
]

status_counts = Counter(
    record["status"]
    for record in records
)

print(status_counts)
```
### Output
```text
Counter({
    'success': 3,
    'failed': 2
})
```
This is a very useful ETL pattern.
```text
records
   ↓
extract status
   ↓
Counter
   ↓
frequency of each status
```

# 8. Find Duplicate Values
### Python
```python
from collections import Counter
customer_ids = [101, 102, 101, 103, 102, 104]
counts = Counter(customer_ids)

duplicates = [
    customer_id
    for customer_id, count in counts.items()
    if count > 1
]
print(duplicates)
```

### Output
```text
[101, 102]
```

This is useful for **data-quality checks**.

# `Counter` vs `set`
This is important.
## Set
### Python
```python
numbers = [1, 2, 2, 3, 3, 3]
unique = set(numbers)
print(unique)
```

### Output
```text
{1, 2, 3}
```

A set tells you:
> What unique values exist?

---
## Counter

### Python
```python
from collections import Counter
numbers = [1, 2, 2, 3, 3, 3]
counts = Counter(numbers)
print(counts)
```
### Output
```text
Counter({3: 3, 2: 2, 1: 1})
```
A Counter tells you:
> How many times does each value occur?
---

# Set vs Counter
```text
SET
→ unique values
Counter
→ frequency of values
```
Example:
```text
Input:
[1, 2, 2, 3, 3, 3]

set:
{1, 2, 3}

Counter:
1 → 1
2 → 2
3 → 3
```

# Counter Complexity
For `n` input items:
```text
Counting → O(n)
```
Getting a count:

### Python
```python
counts[value]
```
is approximately:

```text
O(1)
```
on average.

# Important Interview Question

## Q: Why use `Counter` instead of manually counting with a dictionary?
You can manually do:

### Python
```python
counts = {}
for value in numbers:
    if value not in counts:
        counts[value] = 0

    counts[value] += 1
```
But `Counter` provides a cleaner and purpose-built solution:

### Python
```python
from collections import Counter
counts = Counter(numbers)
```
