# Python Multithreading — Complete Notes

## 1. What is Multithreading?

Multithreading means running multiple threads within the same process.

A **thread** is a unit of execution. Threads belonging to the same process share the process's memory.

Multithreading is mainly useful for **I/O-bound work**, such as:

* API calls
* Database queries
* Network requests
* File I/O
* Waiting for external services

In CPython, the **GIL (Global Interpreter Lock)** means only one thread executes Python bytecode at a time, so multithreading usually does not provide true parallelism for CPU-heavy Python code.

```text
I/O-bound  → Multithreading
CPU-bound  → Multiprocessing
```

## 2. Creating a Thread with `threading.Thread`

The basic way to create a thread is using `threading.Thread`.

```python
import threading
import time


def task(name):
    print(f"{name} started")
    time.sleep(2)
    print(f"{name} finished")


thread1 = threading.Thread(
    target=task,
    args=("Task 1",)
)

thread2 = threading.Thread(
    target=task,
    args=("Task 2",)
)

thread1.start()
thread2.start()

thread1.join()
thread2.join()

print("All tasks completed")
```

### Important arguments

```python
threading.Thread(
    target=function,
    args=(arguments,),
    kwargs={},
    name="thread-name",
    daemon=True
)
```

* `target` → function executed by the thread
* `args` → positional arguments
* `kwargs` → keyword arguments
* `name` → thread name
* `daemon` → whether the thread is a daemon thread

## 3. `start()` vs `run()`

Use:

```python
thread.start()
```

to actually start a new thread.

Do **not** normally call:

```python
thread.run()
```

directly.

Example:

```python
import threading


def task():
    print("Running task")


thread = threading.Thread(target=task)

thread.start()
thread.join()
```

Calling:

```python
thread.run()
```

directly executes the function in the current thread. It does not create a new thread.

## 4. `join()`

`join()` makes the current thread wait until another thread finishes.

```python
import threading
import time


def task():
    time.sleep(2)
    print("Task finished")


thread = threading.Thread(target=task)

thread.start()

print("Waiting for thread...")

thread.join()

print("Thread completed")
```

Without `join()`, the main thread can continue executing while the worker thread is still running.

### Timeout with `join()`

```python
thread.join(timeout=1)
```

This waits at most one second.

If the thread is still running after one second:

```python
print(thread.is_alive())
```

can be used to check its status.

## 6. Creating a Thread Using a Class

Instead of passing a function, you can subclass `threading.Thread`.

```python
import threading


class Worker(threading.Thread):

    def run(self):
        print("Worker thread is running")


thread = Worker()

thread.start()
thread.join()
```

When `start()` is called, Python executes the `run()` method in the new thread.

You can also pass arguments through `__init__`:

```python
import threading


class Worker(threading.Thread):

    def __init__(self, name):
        super().__init__()
        self.name = name

    def run(self):
        print(f"{self.name} is running")


thread = Worker("Worker-1")

thread.start()
thread.join()
```

### Which approach is preferred?

Usually:

```python
threading.Thread(target=function)
```

is simpler and preferred when you just need to execute a function.

Subclassing `Thread` is useful when the thread needs its own state/behavior.

## 7. Passing Arguments to Threads

### Positional arguments

```python
import threading


def task(name, number):
    print(name, number)


thread = threading.Thread(
    target=task,
    args=("Worker", 10)
)

thread.start()
thread.join()
```

### Keyword arguments

```python
import threading


def task(name, number):
    print(name, number)


thread = threading.Thread(
    target=task,
    kwargs={
        "name": "Worker",
        "number": 10
    }
)

thread.start()
thread.join()
```

## 8. Creating Multiple Threads Dynamically

Instead of manually creating every thread:

```python
import threading


def task(number):
    print(f"Processing {number}")


threads = []

for number in range(5):
    thread = threading.Thread(
        target=task,
        args=(number,)
    )

    threads.append(thread)
    thread.start()


for thread in threads:
    thread.join()

print("All tasks completed")
```

This pattern is useful when processing a collection of independent tasks.

## 9. Getting the Current Thread

Use:

```python
threading.current_thread()
```

Example:

```python
import threading


def task():
    thread = threading.current_thread()

    print("Name:", thread.name)
    print("ID:", thread.ident)


thread = threading.Thread(
    target=task,
    name="Worker-1"
)

thread.start()
thread.join()
```

You can also get the main thread:

```python
print(threading.main_thread())
```

## 10. `threading.active_count()`

Returns the number of currently active threads.

```python
import threading
import time


def task():
    time.sleep(2)


thread = threading.Thread(target=task)

thread.start()

print(threading.active_count())

thread.join()
```

## 11. Daemon Threads

A daemon thread is a background thread.

Daemon threads do not keep the Python process alive when all non-daemon threads have finished.

```python
import threading
import time


def background_task():
    while True:
        print("Background task running")
        time.sleep(1)


thread = threading.Thread(
    target=background_task,
    daemon=True
)

thread.start()

time.sleep(3)

print("Main program finished")
```

When the main program exits, the daemon thread is automatically stopped.

### Important

Daemon threads should not normally be used for work that must complete, such as:

* database writes
* critical file operations
* financial transactions
* important ETL processing

Use them for background activities where abrupt termination is acceptable.

## 12. Thread Exceptions

Exceptions inside a thread do not automatically propagate to the main thread when using `threading.Thread`.

Example:

```python
import threading


def task():
    raise ValueError("Something went wrong")


thread = threading.Thread(target=task)

thread.start()
thread.join()

print("Main thread continues")
```

The worker thread prints an exception traceback, but the main thread continues.

### Handling exceptions inside the thread

```python
import threading


def task():
    try:
        raise ValueError("Something went wrong")
    except Exception as e:
        print("Thread error:", e)


thread = threading.Thread(target=task)

thread.start()
thread.join()
```

## 13. Returning a Result from `Thread`

A normal `Thread` does not directly return the function result.

This does not work:

```python
result = thread.start()
```

`start()` returns `None`.

One simple solution is to store the result somewhere shared:

```python
import threading


result = None


def task():
    global result
    result = 10 * 20


thread = threading.Thread(target=task)

thread.start()
thread.join()

print(result)
```

However, for returning results and handling exceptions, `ThreadPoolExecutor` is usually better.
