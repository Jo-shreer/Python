# AWS VPC Notes: Services vs Network Components

## 1. Compute Services

Services that run applications or workloads.

- **EC2** — virtual machines running in VPC subnets.
- **ECS on EC2** — containers running on EC2 instances.
- **ECS Fargate** — serverless containers with ENIs in your subnets.
- **EKS** — managed Kubernetes; worker nodes and pods can run in your VPC.
- **Lambda** — serverless functions; can attach to your VPC when private resource access is needed.

## 2. Database and Storage Services

Managed data services that can reside in, attach to, or integrate with your VPC.

- **RDS** — managed relational databases in VPC subnets.
- **Aurora** — managed relational database compatible with MySQL or PostgreSQL.
- **ElastiCache** — managed in-memory caching in your VPC.
- **MemoryDB** — managed in-memory database in your VPC.
- **Redshift** — managed data warehouse with VPC deployment options.
- **OpenSearch Service** — managed search and analytics; supports VPC deployment.
- **MSK** — managed Apache Kafka brokers in your VPC.
- **Amazon MQ** — managed message brokers with VPC deployment options.
- **EFS** — managed file storage accessed through VPC mount targets.
- **FSx** — managed file systems with VPC connectivity options.

## 3. AWS-Managed Services Outside Your VPC

These services run on AWS-managed infrastructure rather than as resources deployed in your subnets.

- **S3** — object storage.
- **DynamoDB** — NoSQL database.
- **SQS** — message queues.
- **SNS** — pub/sub messaging and notifications.
- **EventBridge** — event routing.
- **Secrets Manager** — secret storage and rotation.
- **Systems Manager (SSM)** — fleet management and operations.
- **CloudWatch** — monitoring and metrics.
- **CloudWatch Logs** — log collection and storage.
- **ECR** — container image registry.
- **KMS** — encryption key management.
- **STS** — temporary AWS credentials.
- **Step Functions** — workflow orchestration.
- **API Gateway** — managed API front door.
- **Glue** — data integration and ETL.
- **Bedrock** — managed generative AI services.
- **CodeArtifact** — package repository.
- **AppConfig** — application configuration.
- **CloudFormation** — infrastructure provisioning.
- **AWS Backup** — backup management.
- **Cognito** — application identity and authentication.
- **AWS Organizations** — multi-account management.

Private access is available for many of these services through supported VPC endpoints. Availability varies by service, API, and Region.

## 4. VPC Network Components

These components provide connectivity, routing, traffic control, or private access. They are not application services.

### VPC and Subnet Basics

- **VPC** — logically isolated network.
- **Subnet** — IP address range inside a VPC, associated with an Availability Zone.
- **Route table** — determines where network traffic is sent.
- **Network ACL (NACL)** — stateless subnet-level traffic filtering.
- **Security group** — stateful traffic filtering for supported network interfaces and resources.
- **Elastic Network Interface (ENI)** — virtual network interface attached to a resource.
- **Secondary private IP** — additional private IP address assigned to an interface.

### Internet and Outbound Connectivity

- **Internet Gateway (IGW)** — provides a path between a VPC and the internet when routing and addressing permit.
- **NAT Gateway** — allows private-subnet resources to initiate supported outbound connections without directly accepting unsolicited internet connections.
- **Egress-only Internet Gateway** — supports outbound IPv6 internet connectivity while preventing internet-initiated inbound connections.

### Private Connectivity to AWS Services

- **Gateway VPC endpoint** — private routing to supported services, especially S3 and DynamoDB.
- **Interface VPC endpoint (AWS PrivateLink)** — uses endpoint network interfaces to privately access supported services.
- **Gateway Load Balancer endpoint** — directs traffic to supported virtual network appliances.

### Load Balancing and Traffic Inspection

- **Application Load Balancer (ALB)** — Layer 7 load balancing for HTTP/HTTPS.
- **Network Load Balancer (NLB)** — Layer 4 load balancing for TCP, UDP, and supported protocols.
- **Gateway Load Balancer (GWLB)** — distributes traffic to virtual network appliances.
- **AWS Network Firewall** — managed network traffic filtering and inspection.

### Connecting Networks

- **VPC Peering** — private connection between two VPCs.
- **Transit Gateway** — central hub connecting multiple VPCs and networks.
- **Site-to-Site VPN** — encrypted connection between a VPC and an external network.
- **AWS Direct Connect** — dedicated network connectivity to AWS.
- **AWS Client VPN** — remote-user VPN connectivity to supported VPC resources.
- **Virtual Private Gateway (VGW)** — VPN and Direct Connect attachment option for a VPC.
- **Customer Gateway** — AWS representation of the customer-side VPN device or endpoint.

### DNS and Addressing

- **Route 53 Resolver** — DNS resolution between VPCs and connected networks.
- **Route 53 private hosted zone** — private DNS records for associated VPCs.
- **Elastic IP address** — static public IPv4 address that can be associated with supported resources.
- **VPC DHCP option set** — configuration for DHCP-provided network settings.

## 5. Quick Decision Summary

- **Run application code:** EC2, ECS, EKS, Lambda.
- **Store relational data:** RDS, Aurora.
- **Store NoSQL data:** DynamoDB.
- **Store objects/files:** S3, EFS, FSx.
- **Queue or route messages:** SQS, SNS, EventBridge.
- **Privately access AWS-managed services:** VPC endpoints.
- **Allow private-subnet workloads outbound internet access:** NAT Gateway, where required.
- **Accept public web traffic:** Internet-facing ALB/NLB with suitable subnet and security design.
- **Connect two VPCs:** VPC Peering or Transit Gateway.
- **Connect an office or data center:** Site-to-Site VPN or Direct Connect.
- **Filter traffic:** Security groups, NACLs, and AWS Network Firewall, each at its appropriate layer.

**Remember:** Application services provide compute, data, or business capabilities. Network components connect, route, filter, and secure traffic. AWS-managed services do not become part of your VPC just because you access them through a VPC endpoint.
