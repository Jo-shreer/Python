# Enterprise Document Ingestion and Normalisation
## Improved implementation: S3 streaming download + temporary files + document extraction

## 1. What are we building?

Our previous stage stored SharePoint documents in Amazon S3.

Now we need to read those documents, extract their contents and convert them into a standard structure.

This implementation improves the previous version by using temporary files rather than loading the original file into Python memory.

Our pipeline:

```text
                  SHAREPOINT
                       |
                       v
                 Amazon S3
                Raw Documents
                       |
                       v
                  S3 Reader
                       |
                       v
             Temporary Local File
                       |
                       v
                 File Detector
                       |
                       v
              Extraction Router
                       |
        +--------------+--------------+
        |              |              |
       PDF            DOCX           XLSX
        |              |              |
      pypdf        python-docx      openpyxl
        |              |              |
        +--------------+--------------+
                       |
                Other Extractors
                       |
                       v
              Normalisation Layer
                       |
                       v
                   Validation
                       |
                       v
             Temporary JSON File
                       |
                       v
                 Amazon S3
              Processed Documents
                       |
                       v
                Next: Chunking
                       |
                       v
              Embedding Generation
                       |
                       v
                Amazon OpenSearch
```

## 2. What has changed from the previous implementation?

Previously, we used:

```python
response = s3_client.get_object(
    Bucket=bucket,
    Key=key
)

file_content = response["Body"].read()
```

The problem is that `.read()` loads the entire original file into memory.

Imagine that the original document is 500 MB. Python may need to hold approximately that much binary data in memory, in addition to the extracted text and other processing objects.

We will replace that approach with:

```python
s3_client.download_file(
    Bucket=bucket,
    Key=key,
    Filename=temporary_file_path
)
```

This downloads the S3 object directly to a file on local disk.

The extraction libraries can then read that file.

### Why use a temporary file?

| Advantage | Explanation |
|---|---|
| Lower memory usage | The original binary does not need to be loaded into a Python bytes variable |
| Large-file support | Boto3 manages multipart downloads where necessary |
| Library compatibility | PDF, Word, Excel and PowerPoint libraries can work with file paths |
| Automatic cleanup | Temporary files can be deleted after processing |
| Better resource management | Memory and disk usage can be controlled separately |

Important: Temporary-file processing does not mean that every extraction library is fully streaming. Some libraries still construct document structures or extracted text in memory. We will explain that limitation later.

- Complex tables, charts and embedded images may need specialised extraction.

# 5. Common normalised document structure

Every extractor must return content in a consistent structure.

For example:

```python
normalised_document = {

    "document_id": "file-001",

    "source": {
        "system": "sharepoint",
        "drive_id": "drive-123",
        "item_id": "file-001"
    },

    "file": {
        "name": "Employee_Policy.pdf",
        "extension": ".pdf",
        "mime_type": "application/pdf",
        "size_bytes": 15240,
        "checksum_sha256": "example_checksum"
    },

    "storage": {
        "bucket": "company-documents",
        "key": "documents/sharepoint/drive-123/file-001"
    },

    "content": {
        "text": "Employees are entitled to 25 days of annual leave.",
        "sections": []
    },

    "metadata": {},

    "processing": {
        "status": "extracted",
        "extraction_method": "pdf"
    }

}
```

The common fields allow us to process different file formats using the same downstream pipeline.

The business-specific metadata can still differ between documents.

def detect_file_type(file_name, content_type):

    extension = Path(
        file_name
    ).suffix.lower()

    detected_mime_type, _ = mimetypes.guess_type(
        file_name
    )

    mime_type = (
        detected_mime_type
        or content_type
        or "application/octet-stream"
    )

    return extension, mime_type


# ==========================================================
# STEP 7: CALCULATE FILE CHECKSUM
# ==========================================================

def calculate_checksum(file_path):

    sha256 = hashlib.sha256()

    with open(file_path, "rb") as file:

        while True:

            chunk = file.read(1024 * 1024)

            if not chunk:
                break

            sha256.update(chunk)

    return sha256.hexdigest()


# ==========================================================
# STEP 8: EXTRACT PDF CONTENT

def extract_pdf(file_path):

    pdf_reader = PdfReader(
        str(file_path)
    )

    sections = []

    for page_number, page in enumerate(
        pdf_reader.pages,
        start=1
    ):

        page_text = page.extract_text() or ""

        sections.append({

            "section_type": "page",

            "section_number": page_number,

            "text": page_text.strip()

        })

    full_text = "\n\n".join(

        section["text"]

        for section in sections

        if section["text"]

    )

    return full_text, sections

# STEP 9: EXTRACT DOCX CONTENT
# ==========================================================

def extract_docx(file_path):

    document = Document(
        str(file_path)
    )

    sections = []

    for paragraph_number, paragraph in enumerate(
        document.paragraphs,
        start=1
    ):

        text = paragraph.text.strip()

        if text:

            sections.append({

                "section_type": "paragraph",

                "section_number": paragraph_number,

                "text": text

            })

    for table_number, table in enumerate(
        document.tables,
        start=1
    ):

        rows = []

        for row in table.rows:

            values = [

                cell.text.strip()

                for cell in row.cells

            ]

            rows.append(
                " | ".join(values)
            )

        sections.append({

            "section_type": "table",

            "section_number": table_number,

            "text": "\n".join(rows)

        })

    full_text = "\n\n".join(

        section["text"]

        for section in sections

    )

    return full_text, sections

def extract_xlsx(file_path):

    workbook = load_workbook(

        filename=str(file_path),

        read_only=True,

        data_only=True

    )

    sections = []

    try:

        for worksheet in workbook.worksheets:

            rows = []

            for row in worksheet.iter_rows(
                values_only=True
            ):

                values = [

                    str(value)

                    for value in row

                    if value is not None

                ]

                if values:

                    rows.append(
                        " | ".join(values)
                    )

            sections.append({

                "section_type": "worksheet",

                "section_name": worksheet.title,

                "text": "\n".join(rows)

            })

    finally:

        workbook.close()

    full_text = "\n\n".join(

        section["text"]

        for section in sections

    )

    return full_text, sections

def extract_xls(file_path):

    workbook = xlrd.open_workbook(
        filename=str(file_path)
    )

    sections = []

    for sheet in workbook.sheets():

        rows = []

        for row_number in range(sheet.nrows):

            values = []

            for column_number in range(sheet.ncols):

                value = sheet.cell_value(

                    row_number,

                    column_number

                )

                if value != "":

                    values.append(str(value))

            if values:

                rows.append(
                    " | ".join(values)
                )

        sections.append({

            "section_type": "worksheet",

            "section_name": sheet.name,

            "text": "\n".join(rows)

        })

    full_text = "\n\n".join(

        section["text"]

        for section in sections

    )

    return full_text, sections

def extract_pptx(file_path):

    presentation = Presentation(
        str(file_path)
    )

    sections = []

    for slide_number, slide in enumerate(
        presentation.slides,
        start=1
    ):

        slide_content = []

        for shape in slide.shapes:

            if shape.has_text_frame:

                if shape.text.strip():

                    slide_content.append(
                        shape.text.strip()
                    )

            if shape.has_table:

                for row in shape.table.rows:

                    values = [

                        cell.text.strip()

                        for cell in row.cells

                    ]

                    slide_content.append(
                        " | ".join(values)
                    )

        sections.append({

            "section_type": "slide",

            "section_number": slide_number,

            "text": "\n".join(slide_content)

        })

    full_text = "\n\n".join(

        section["text"]

        for section in sections

    )

    return full_text, sections

def extract_csv(file_path):

    sections = []

    with open(

        file_path,

        "r",

        encoding="utf-8-sig",

        errors="replace",

        newline=""

    ) as file:

        reader = csv.DictReader(file)

        for row_number, row in enumerate(
            reader,
            start=1
        ):

            row_text = []

            for column, value in row.items():

                if column and value:

                    row_text.append(
                        f"{column}: {value}"
                    )

            sections.append({

                "section_type": "record",

                "section_number": row_number,

                "text": "\n".join(row_text)

            })

    full_text = "\n\n".join(

        section["text"]

        for section in sections

    )

    return full_text, sections

                "section_number": line_number,

                "text": record_text

        section["text"]

        for section in sections

    return full_text, sections

def extract_html(file_path):

    with open(

        file_path,

        "r",

        encoding="utf-8",

        errors="replace"

        soup = BeautifulSoup(

            file,

        "style",

        separator="\n",

        strip=True

    sections = [{

        "section_type": "html_content",

        "section_number": 1,

        "text": text

    }]

    return text, sections

def extract_eml(file_path):

    with open(

        file_path,

        "rb"

    ) as file:

        message = BytesParser(
            policy=policy.default
        ).parse(file)

    body_parts = []

    if message.is_multipart():

        for part in message.walk():

            if part.get_content_type() == "text/plain":

                body_parts.append(
                    part.get_content()
                )

    else:

        if message.get_content_type() == "text/plain":

            body_parts.append(
                message.get_content()
            )

    body = "\n".join(body_parts)

    text = (

        f"Subject: {message.get('subject', '')}\n"

        f"From: {message.get('from', '')}\n"

        f"To: {message.get('to', '')}\n"

        f"Date: {message.get('date', '')}\n\n"

        f"{body}"

    )

    sections = [{

        "section_type": "email",

        "section_number": 1,

        "text": text.strip()

    }]

    return text.strip(), sections

# STEP 22: EXTRACT USING AMAZON TEXTRACT
# ==========================================================

def extract_with_textract(bucket, key):

    logger.info(
        "Starting asynchronous Textract job: %s",
        key
    )

    response = textract_client.start_document_text_detection(

        DocumentLocation={

            "S3Object": {

                "Bucket": bucket,

                "Name": key

            }

        }

    )

    job_id = response["JobId"]

    logger.info(
        "Textract Job ID: %s",
        job_id
    )

    start_time = time.monotonic()

    while True:

        result = textract_client.get_document_text_detection(

            JobId=job_id

        )

        job_status = result["JobStatus"]

        if job_status in [

            "SUCCEEDED",

            "PARTIAL_SUCCESS"

        ]:

            break

        if job_status == "FAILED":

            raise RuntimeError(
                f"Textract failed for {key}"
            )

        elapsed = (
            time.monotonic() - start_time
        )

        if elapsed > TEXTRACT_MAX_WAIT_SECONDS:

            raise TimeoutError(
                f"Textract timed out for {key}"
            )

        time.sleep(
            TEXTRACT_POLL_INTERVAL
        )

    sections = []

    page_lines = []

    page_number = 1

    next_token = None

    while True:

        request = {

            "JobId": job_id

        }

        if next_token:

            request["NextToken"] = next_token

        result = textract_client.get_document_text_detection(
            **request
        )

        for block in result.get("Blocks", []):

            if block["BlockType"] == "LINE":

                page = block.get(
                    "Page",
                    1
                )

                while page_number < page:

                    sections.append({

                        "section_type": "page",

                        "section_number": page_number,

                        "text": "\n".join(page_lines)

                    })

                    page_lines = []

                    page_number += 1

                page_lines.append(
                    block["Text"]
                )

        next_token = result.get(
            "NextToken"
        )

        if not next_token:
            break

    if page_lines:

        sections.append({

            "section_type": "page",

            "section_number": page_number,

            "text": "\n".join(page_lines)

        })

    full_text = "\n\n".join(

        section["text"]

        for section in sections

    )

    return full_text, sections

# STEP 23: EXTRACTION ROUTER
# ==========================================================

def extract_document(

    file_path,

    extension,

    bucket,

    s3_key

):

    logger.info(
        "Selecting extractor for: %s",
        extension
    )

    extractors = {

        ".pdf": extract_pdf,

        ".docx": extract_docx,

        ".xlsx": extract_xlsx,

        ".xls": extract_xls,

        ".pptx": extract_pptx,

        ".csv": extract_csv,

        ".json": extract_json,

        ".jsonl": extract_jsonl,

        ".txt": extract_text,

        ".md": extract_text,

        ".rtf": extract_rtf,

        ".html": extract_html,

        ".htm": extract_html,

        ".xml": extract_xml,

        ".eml": extract_eml,

        ".msg": extract_msg_file

    }

    # OCR-supported file formats

    ocr_extensions = [

        ".png",

        ".jpg",

        ".jpeg",

        ".tif",

        ".tiff"

    ]

    if extension in ocr_extensions:

        if not TEXTRACT_ENABLED:

            raise ValueError(
                "Textract is disabled"
            )

        return extract_with_textract(
            bucket,
            s3_key
        )

    # First try normal PDF text extraction.
    # If no text exists, try OCR.

    if extension == ".pdf":

        text, sections = extract_pdf(
            file_path
        )

        if text.strip():

            return text, sections

        logger.info(
            "No PDF text found. Trying Textract OCR."
        )

        if not TEXTRACT_ENABLED:

            raise ValueError(
                "Scanned PDF detected but Textract is disabled"
            )

        return extract_with_textract(
            bucket,
            s3_key
        )

    if extension in extractors:

        return extractors[extension](
            file_path
        )

    raise ValueError(
        f"Unsupported extension: {extension}"
    )

# STEP 24: NORMALISE DOCUMENT
# ==========================================================

def normalise_document(

    file_path,

    file_name,

    bucket,

    s3_key,

    source_metadata,

    content_type,

    file_size

):

    extension, mime_type = detect_file_type(

        file_name,

        content_type

    )

    logger.info(
        "Normalising file: %s",
        file_name
    )

    extracted_text, sections = extract_document(

        file_path=file_path,

        extension=extension,

        bucket=bucket,

        s3_key=s3_key

    )

    checksum = calculate_checksum(
        file_path
    )

    normalised_document = {

        "document_id": source_metadata.get(

            "sharepoint-item-id",

            checksum

        ),

        "source": {

            "system": "sharepoint",

            "drive_id": source_metadata.get(
                "sharepoint-drive-id"
            ),

            "item_id": source_metadata.get(
                "sharepoint-item-id"
            )

        },

        "file": {

            "name": file_name,

            "extension": extension,

            "mime_type": mime_type,

            "size_bytes": file_size,

            "checksum_sha256": checksum

        },

        "storage": {

            "bucket": bucket,

            "key": s3_key

        },

        "content": {

            "text": extracted_text,

            "sections": sections

        },

        "metadata": {

            "original_s3_key": s3_key

        },

        "processing": {

            "status": "extracted",

            "extraction_method": extension.lstrip("."),

            "content_characters": len(extracted_text),

            "section_count": len(sections)

        }

    }

    return normalised_document

# STEP 25: VALIDATE DOCUMENT

def validate_document(document):

    errors = []

    if not document.get("document_id"):

        errors.append(
            "Missing document ID"
        )

    if not document["file"].get("name"):

        errors.append(
            "Missing file name"
        )

    if not document["content"].get("text"):

        errors.append(
            "No extractable text"
        )

    if not document["storage"].get("key"):

        errors.append(
            "Missing S3 source key"
        )

    return errors


# ==========================================================
# STEP 26: SAVE NORMALISED JSON TO TEMPORARY FILE
# ==========================================================

def save_json_to_temp_file(document, local_path):

    with open(

        local_path,

        "w",

        encoding="utf-8"

    ) as file:

        json.dump(

            document,

            file,

            indent=2,

            ensure_ascii=False

        )


# ==========================================================
# STEP 27: UPLOAD NORMALISED JSON TO S3
# ==========================================================

def upload_normalised_json(document, json_file_path):

    document_id = document["document_id"]

    output_key = (

        f"{PROCESSED_PREFIX}"

        f"{document_id}.json"

    )

    s3_client.upload_file(

        Filename=str(json_file_path),

        Bucket=S3_BUCKET,

        Key=output_key,

        ExtraArgs={

            "ContentType": "application/json"

        }

    )

    logger.info(
        "Normalised JSON uploaded to s3://%s/%s",
        S3_BUCKET,
        output_key
    )

    return output_key


# ==========================================================
# STEP 28: PROCESS ONE DOCUMENT
# ==========================================================

def process_s3_document(s3_key):

    logger.info(
        "Starting document processing: %s",
        s3_key
    )

    # Read metadata before downloading

    metadata, file_size, content_type = get_s3_metadata(

        S3_BUCKET,

        s3_key

    )

    file_name = metadata.get(

        "original-file-name",

        os.path.basename(s3_key)

    )

    extension, _ = detect_file_type(

        file_name,

        content_type

    )

    # Create a temporary working directory.
    # It is automatically removed after the block finishes.

    with tempfile.TemporaryDirectory(

        prefix="document_processing_"

    ) as temp_directory:

        temp_directory = Path(
            temp_directory
        )

        # Preserve the extension so libraries can identify formats

        temp_file_path = (
            temp_directory / f"source{extension}"
        )

        json_file_path = (
            temp_directory / "normalised.json"
        )

        # Download original document to disk

        download_to_temp_file(

            S3_BUCKET,

            s3_key,

            temp_file_path

        )

        # Extract and normalise document

        document = normalise_document(

            file_path=temp_file_path,

            file_name=file_name,

            bucket=S3_BUCKET,

            s3_key=s3_key,

            source_metadata=metadata,

            content_type=content_type,

            file_size=file_size

        )

        # Validate normalised result

        validation_errors = validate_document(
            document
        )

        if validation_errors:

            raise ValueError(
                "; ".join(validation_errors)
            )

        # Save JSON to temporary disk file

        save_json_to_temp_file(

            document,

            json_file_path

        )

        # Upload JSON file to S3

        output_key = upload_normalised_json(

            document,

            json_file_path

        )

    # Temporary directory is automatically deleted here

    logger.info(
        "Processing completed: %s",
        file_name
    )

    return output_key

# 7. Detailed explanation of the improved implementation

## A. How does the S3 download now work?

The most important change is here:

```python
s3_client.download_file(

    Bucket=bucket,

    Key=key,

    Filename=str(local_path)

)
```

This is a Boto3 managed file download.

Understand the parameters:

| Parameter | Meaning |
|---|---|
| `Bucket` | The S3 bucket containing the original document |
| `Key` | The complete S3 object key |
| `Filename` | Local destination path where the downloaded file is saved |

For example:

```python
Bucket = "company-documents"

Key = "documents/sharepoint/drive-123/file-001"

Filename = "/tmp/document_processing/source.pdf"
```

The original file is downloaded to the temporary local file.

Boto3's managed download supports multipart transfers where appropriate.

This is useful for larger files because we are not calling `.read()` to load the complete original object into a Python bytes variable.

## B. How do temporary directories work?

We use:

```python
with tempfile.TemporaryDirectory(
    prefix="document_processing_"
) as temp_directory:
```

`TemporaryDirectory()` creates a temporary folder on the machine running Python.

For example:

```text
/tmp/document_processing_abcd123/
```

Then:

```python
temp_file_path = (
    temp_directory / f"source{extension}"
)
```

Creates a local path such as:

```text
/tmp/document_processing_abcd123/source.pdf
```

The `with` statement provides automatic cleanup.

When execution leaves the block, Python removes the temporary directory and its contents.

This happens when the block exits normally or when an exception occurs.

This is why we do not need to manually delete every temporary file.

## C. Why do we call `head_object` before downloading?

```python
response = s3_client.head_object(
    Bucket=bucket,
    Key=key
)
```

`head_object()` retrieves information about an S3 object without downloading its contents.

We use it to obtain:

```python
metadata = response.get("Metadata", {})

file_size = response["ContentLength"]

content_type = response.get(
    "ContentType",
    "application/octet-stream"
)
```

These values are useful:

| Attribute | Meaning |
|---|---|
| `Metadata` | Custom metadata attached to the S3 object |
| `ContentLength` | Original file size in bytes |
| `ContentType` | S3 content type |

For example:

```text
ContentLength = 52428800
ContentType = application/pdf
```

This tells us that the file is approximately 50 MB and is identified as a PDF by its S3 content type.

We also obtain the original file name from the custom metadata.

## D. Why calculate the checksum using blocks?

Previously, we used:

```python
hashlib.sha256(file_content).hexdigest()
```

That required the complete file to be in memory.

Now we use:

```python
with open(file_path, "rb") as file:

    while True:

        chunk = file.read(1024 * 1024)

        if not chunk:
            break

        sha256.update(chunk)
```

Understand these parameters:

- `"rb"`: Opens the file in binary read mode.
- `1024 * 1024`: Reads approximately 1 MB at a time.
- `sha256.update()`: Adds the current block to the checksum calculation.
- `hexdigest()`: Returns the final hexadecimal checksum.

This is a genuine block-by-block processing operation.

We do not need the whole original file in memory to calculate its checksum.

## E. How does the PDF extraction work now?

Previously:

```python
pdf_reader = PdfReader(
    io.BytesIO(file_content)
)
```

Now:

```python
pdf_reader = PdfReader(
    str(file_path)
)
```

We pass the local file path directly to pypdf.

The library reads the PDF from disk.

For every page:

```python
for page_number, page in enumerate(
    pdf_reader.pages,
    start=1
):
```

- `pdf_reader.pages`: Accesses PDF pages.
- `enumerate()`: Gives each page a number.
- `start=1`: Starts page numbering at 1.

Then:

```python
page_text = page.extract_text() or ""
```

Extracts available text from the page.

If the PDF is scanned and has no extractable text, we attempt OCR using Textract.

Important: pypdf itself may still use memory for PDF structures. Passing a path does not make PDF parsing completely memory-free.

## F. How does Excel extraction work?

```python
workbook = load_workbook(
    filename=str(file_path),
    read_only=True,
    data_only=True
)
```

There are three important parameters:

| Parameter | Meaning |
|---|---|
| `filename` | The Excel workbook file path |
| `read_only=True` | Opens the workbook in read-only mode, which is more memory-efficient |
| `data_only=True` | Reads cached formula results when available |

Next:

```python
for worksheet in workbook.worksheets:
```

This iterates through every worksheet.

Then:

```python
for row in worksheet.iter_rows(
    values_only=True
):
```

Reads rows as cell values rather than creating full cell objects.

We preserve the worksheet name:

```python
"section_name": worksheet.title
```

This is important because later, when we create chunks, we want to know which worksheet the information came from.

We close the workbook using:

```python
workbook.close()
```

The `finally` block ensures the workbook is closed even if extraction fails.

## G. How does the Textract integration work?

This is our scanned-document extraction path.

```python
response = textract_client.start_document_text_detection(

    DocumentLocation={

        "S3Object": {

            "Bucket": bucket,

            "Name": key

        }

    }

)
```

Notice something important.

We do not download the PDF or image to Python and then pass its binary contents to Textract.

Instead, we provide its existing S3 location.

Textract processes the document directly from S3.

The response provides:

```python
job_id = response["JobId"]
```

The job ID identifies the asynchronous Textract job.

We then call:

```python
textract_client.get_document_text_detection(
    JobId=job_id
)
```

This checks the job's status and retrieves results.

The result can be:

- `IN_PROGRESS`
- `SUCCEEDED`
- `PARTIAL_SUCCESS`
- `FAILED`

After successful processing, we collect the text blocks.

We also follow `NextToken` to retrieve all result pages.

This is important because a large document's OCR results may be split across multiple API responses.

For enterprise deployments, an SNS/SQS notification workflow is preferable to continuously polling for completion. The example uses polling to keep the learning code understandable.

## H. How does the extraction router work?

```python
extractors = {

    ".pdf": extract_pdf,

    ".docx": extract_docx,

    ".xlsx": extract_xlsx,

    ".csv": extract_csv

}
```

The dictionary connects file extensions to their extraction functions.

For example:

```python
extractors[".pdf"]
```

Returns the PDF extraction function.

The router executes the selected function:

```python
return extractors[extension](file_path)
```

This means we can add another format later without rewriting the rest of the pipeline.

## I. Why save the normalised JSON to a temporary file too?

Previously, we used:

```python
json_content = json.dumps(document)
```

This creates the complete JSON string in memory.

For a large extracted document, this may create another substantial memory allocation.

We now use:

```python
with open(
    local_path,
    "w",
    encoding="utf-8"
) as file:

    json.dump(
        document,
        file,
        indent=2,
        ensure_ascii=False
    )
```

`json.dump()` writes the JSON representation to a file.

Then:

```python
s3_client.upload_file(
    Filename=str(json_file_path),
    Bucket=S3_BUCKET,
    Key=output_key
)
```

Uploads the local JSON file to S3.

This avoids creating another complete JSON string in memory.

However, the `document` Python dictionary itself still contains the extracted text and sections. We will address that in the next scalability improvement.

# 9. Does this completely solve the large-file memory problem?

It solves an important part of it, but I want to be precise.

There are three separate memory considerations.

### A. Original file download

**Improved:**

```python
s3_client.download_file(...)
```

The original file is downloaded to disk rather than loaded into a Python bytes variable.

### B. Document extraction

**Partially improved:**

We pass file paths to extraction libraries.

Some libraries, however, still load document structures or extracted content into memory.

Examples:

- pypdf can retain PDF structures in memory.
- DOCX parsing constructs document objects.
- PowerPoint parsing constructs presentation objects.
- JSON parsing loads the parsed JSON structure.
- HTML parsing constructs a document tree.
- Text and RTF extraction may create large strings.

The Excel XLSX example uses `read_only=True`, which helps reduce memory consumption.

### C. Normalised output

**Partially improved:**

We write JSON to a temporary file and upload it from disk.

But our normalised document still contains:

```python
"content": {
    "text": extracted_text,
    "sections": sections
}
```

Therefore, extracted content remains in memory.

### What would a fully scalable design look like?

For very large documents, we should avoid collecting every extracted section into one large Python list.

Instead:

```text
S3 Original File
       |
       v
Temporary File
       |
       v
Format-Specific Extractor
       |
       v
Extract One Page / Row Group / Slide
       |
       v
Normalise That Section
       |
       v
Write Section to Temporary Output
       |
       v
Create Chunks
       |
       v
Generate Embeddings
       |
       v
OpenSearch
```

This is a more advanced streaming or incremental processing design.

For example, a 1,000-page PDF should ideally be processed page by page, with chunks written and uploaded progressively rather than retaining all 1,000 pages of extracted text in memory.

We will implement that when we build the chunking stage.

# 10. Important enterprise production considerations

Before deployment, the following should be included:

1. **Temporary disk capacity:** Ensure the processing machine has sufficient temporary storage. A large original file and its processed output may coexist temporarily.
2. **Disk cleanup:** Use temporary directories and monitor available disk space.
3. **Concurrency control:** Limit how many large files are processed simultaneously.
4. **OCR workflow:** Use Textract asynchronous processing with SNS/SQS notifications for larger workloads.
5. **Error handling:** Store processing failures separately and implement retry rules.
6. **File security:** Treat downloaded documents as untrusted input and isolate document processing.
7. **Metadata:** Preserve SharePoint IDs, version information and access-control metadata.
8. **Idempotency:** Use stable document IDs and checksums to prevent unnecessary reprocessing.
9. **Logging:** Record document IDs, file names, processing status and errors.
10. **Large-document extraction:** Move towards page-by-page, row-group or section-by-section extraction and chunking.

The AWS execution role will need appropriate S3 read/write permissions and Textract permissions. Textract also needs access to the input S3 objects.
